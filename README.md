## 📖 简介

**PCL2-Nex** 是一款基于 [Plain Craft Launcher 2 (PCL2)](https://github.com/Meloong-Git/PCL) 及其社区版 [PCL2-CE](https://github.com/PCL-Community/PCL2-CE) 二次开发的启动器项目。

我们在保留原版简洁、流畅体验的基础上，引入了全新的插件架构，并重点扩展了**联机互动**功能。本项目旨在为 Minecraft 玩家提供更灵活、更具扩展性的启动体验。

## ✨ 核心特性

* **插件化核心**：采用独立的 **[nex-plugin-framework](https://github.com/Nex-Devloper/nex-plugin-framework)** 作为底层框架，支持轻量级、模块化的插件扩展。
* **开源共建**：基于社区广泛认可的 PCL2 与 PCL2-CE 代码库构建。
* **联机增强**：内置深度的联机支持，优化多人游戏连接体验。
* **自由定制**：支持深度自定义，允许用户通过插件改变启动器的功能表现。

## 📦 安装与使用

1.  请前往 [Releases](链接) 页面下载最新版本。
2.  解压并运行 `PCL2-Nex.exe`。
3.  根据提示完成 Minecraft 游戏环境配置。
